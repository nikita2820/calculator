# Калькулятор

Консольный калькулятор на Python с интерфейсом на русском языке.

## Запуск

Требуется Python 3.6 или новее. Сторонние библиотеки не нужны.

```bash
python main.py
```

Введите выражение, разделяя числа и знаки операций пробелами:

```text
2 + 3 * 4
```

Результат: `14.0`.

Поддерживаются операции `+`, `-`, `*`, `/`, `//`, `%`, `**`. Сначала вычисляются степени, затем умножение, деление и остаток, затем сложение и вычитание. Операции одной группы выполняются слева направо. Скобки не поддерживаются. Дробные числа вводятся через точку.

После вычисления введите `1`, чтобы продолжить, или `0`, чтобы завершить программу.
